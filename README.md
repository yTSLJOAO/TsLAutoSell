📦 TsLAutoSell
O TsLAutoSell é um plugin de alta performance para servidores Minecraft desenvolvido para otimizar a economia e a jogabilidade. Focado em servidores dos estilos Prison, Skyblock e Survival, ele automatiza a venda de itens acumulados no inventário dos jogadores de forma inteligente, evitando o acúmulo de lixo e reduzindo drasticamente o lag no servidor.
✨ Principais Funcionalidades
 * 💰 Os jogadores podem vender os itens coletados (como minérios e drops de farms) de maneira rápida através de comandos ou automações, mantendo o ritmo fluido de jogo.
 * 🚀 Desenvolvido com foco total em eficiência para suportar servidores com alta quantidade de jogadores online sem impactar o TPS.
 * 🔌 Suporte nativo a plugins de economia através do Vault, garantindo transações financeiras seguras e instantâneas.
 * 🛠️ Arquivos de configuração limpos que permitem aos administradores definirem preços, itens permitidos e mensagens personalizadas com facilidade.
⚙️ Comandos e Permissões
| Comando | Descrição | Permissão | Padrão |
|---|---|---|---|
| /autosell | Abre o menu principal ou vende os itens. | tslautosell.use | Todos |
| /autosell reload | Recarrega as configurações do plugin. | tslautosell.admin | Apenas OP |
